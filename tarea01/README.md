## Etiqueta v1.0-estable

Durante la práctica se creó la etiqueta `v1.0-estable` para marcar una versión importante del proyecto.
Para comprobar las etiquetas creadas se utilizó: `git tag`

Y para visualizar la información y los cambios asociados a la etiqueta: `git show v1.0-estable`
